# 三种方案对比说明（LSTM / SimpleRNN / GRU）

## 1. 任务背景

- **任务**：基于 `LSTM-Multivariate_pollution.csv` 做多变量时间序列回归预测（目标为污染值）。
- **输入**：滑动窗口序列（长度为一周小时数据）。
- **输出**：下一时刻污染值（回归）。
- **评估方式**：同一测试集、同一反归一化流程，指标为 MSE / RMSE / MAE / R²。

## 2. 三种模型结构

- **LSTM**：双层 LSTM（64 -> 32）+ Dropout + Dense 头。
- **SimpleRNN**：双层 SimpleRNN（64 -> 32）+ Dropout + Dense 头。
- **GRU**：双层 GRU（64 -> 32）+ Dropout + Dense 头。

三种方案的训练策略保持一致（优化器、batch size、验证划分和早停策略一致），因此对比结果具有可比性。

## 3. 测试集结果对比

| 模型 | MSE | RMSE | MAE | R² |
|---|---:|---:|---:|---:|
| LSTM | 541.4547 | 23.2692 | 12.3049 | 0.9383 |
| SimpleRNN | 573.1438 | 23.9404 | 13.3843 | 0.9347 |
| GRU | 528.7981 | 22.9956 | 12.2503 | 0.9397 |

## 4. 结果解读

- **整体最优：GRU**  
  在本实验中，GRU 在 MSE、RMSE、MAE、R² 四项指标上都略优于 LSTM，说明其在该数据集上取得了最好的精度与泛化表现。

- **次优：LSTM**  
  LSTM 与 GRU 指标接近，表现稳定；对较长时依赖通常更有表达能力，但参数更多、训练开销相对更高。

- **相对较弱：SimpleRNN**  
  SimpleRNN 指标明显落后，主要因为其门控机制不足，较难稳定建模复杂长期依赖。

## 5. 三种方案的优缺点

### LSTM
- **优点**：记忆能力强，长期依赖建模能力好，结果稳定。
- **缺点**：参数量较大，训练和推理开销较高。

### SimpleRNN
- **优点**：结构简单、实现直观、计算开销低。
- **缺点**：容易梯度消失，长序列性能通常较弱。

### GRU
- **优点**：在保持门控能力的同时结构更轻，训练速度和精度通常较平衡。
- **缺点**：在极端长依赖任务上不一定始终优于 LSTM（依赖具体数据）。

## 6. 结论与建议

- 当前实验下，**推荐优先使用 GRU 作为基线生产方案**（精度最佳且结构较轻）。
- 若后续任务更强调长期依赖或可解释门控分析，可进一步尝试更深层 LSTM 或注意力机制增强。
- SimpleRNN 可作为教学或快速原型对照，不建议作为最终方案。
